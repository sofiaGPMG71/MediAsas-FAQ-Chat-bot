# LangChain RAG flow

MediAsas FAQ is a retrieval-augmented generation application that answers questions using uploaded PDF documents. Its purpose is to make policy information easier to locate while allowing users to inspect the original evidence. Streamlit supplies the multi-file uploader, provider selector, chat input, message history, and expandable source panels. The included customer FAQ supports an immediate evaluation without requiring evaluators to locate a document themselves.

Ingestion begins by checking collection size, document count, encryption, and page count. The PDF parser extracts text page by page. Each page retains its original filename and one-based PDF page number. Pages without text produce an OCR warning. LangChain's RecursiveCharacterTextSplitter divides the extracted documents into chunks of approximately 1,000 characters, with 180 characters of overlap. Overlap reduces the chance that information crossing a chunk boundary becomes impossible to retrieve. Every chunk receives an identifier for traceability.

The selected provider determines both the embedding model and chat model. OpenAI mode uses OpenAIEmbeddings and ChatOpenAI, with credentials loaded from a local .env file. Local mode uses OllamaEmbeddings and ChatOllama, allowing both embedding and generation to run on the user's computer. Embedding vectors are stored in an in-memory LangChain InMemoryVectorStore index. The index belongs to the current Streamlit session and is rebuilt whenever documents or model settings change. An additional offline demonstration uses lexical hashing vectors and exact excerpts; it explicitly does not perform LLM generation.

For each question, a LangChain retriever searches LangChain InMemoryVectorStore and returns the four closest chunks. In LLM modes, recent conversation can first be used to rewrite a follow-up into a standalone search question. This helps resolve references such as “Does that change as I get older?” without treating earlier assistant messages as factual evidence. Retrieved chunks are labelled S1 through S4 and assembled with the current question into a ChatPromptTemplate. LangChain composes that prompt, the selected language model, and a string output parser into the answering chain.

The system prompt requires answers to use only supplied evidence, cite supporting chunk labels, and acknowledge unavailable information. It also tells the model to treat instructions embedded in documents as untrusted content. Generated responses without valid evidence labels are replaced with a missing-answer message. The interface displays source filenames, page numbers, chunk identifiers, and extracted text so users can review the answer. These controls reduce unsupported responses but cannot guarantee correctness: retrieval can miss evidence and models can misinterpret tables or attach misleading citations. Evaluation therefore combines automated ingestion and refusal checks with manual review of answers against original pages.
